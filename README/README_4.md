객체지향 II - 상속/다형성/추상화

## ⚙️ 실행 방법
<!-- Java 파일 또는 Spring 프로젝트 실행 방법을 작성해 주세요 -->
step1  
사용자로부터 아기사자 또는 운영진 역할을 선택받습니다.

step2  
이름, 전공, 기수, 파트 등 기본 정보를 입력받습니다.

step3  
입력받은 역할에 따라 Lion 또는 Staff 객체를 생성합니다.

step4  
추상 클래스 Role을 상속받은 객체를 통해 정보를 출력하고, 인터페이스를 활용해 과제 제출 가능 여부를 확인합니다.

## 💡 작업 내용
- 아기사자와 운영진 정보를 입력받는 프로그램을 구현했습니다.
- Role 추상 클래스를 상속받아 Lion, Staff 클래스를 구현했습니다.
- 인터페이스를 활용해 역할별 과제 제출 가능 여부 정책을 분리했습니다.
- List<Role>을 사용해 Lion과 Staff 객체를 함께 저장했습니다.
- Map<String, List<Role>>을 사용해 파트별 멤버 조회 기능을 구현했습니다.
- 입력받은 멤버 정보를 콘솔에 출력하도록 구현했습니다.
